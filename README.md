# Walentynka

Interaktywna walentynka dla żony. Trzy pytania, uciekający przycisk „Nie” oraz finał z serduszkami.

Strona: https://gmrogalski.github.io/walentynka/

Statyczna strona bez zależności, analityki, formularzy i zapisywania odpowiedzi. Działa myszą, klawiaturą i dotykiem. Uwzględnia preferencję ograniczonych animacji.

## Publikacja

GitHub Pages: Deploy from a branch → main → / (root).

## Edycja

Teksty pytań: `app.js`. Końcowa wiadomość: `index.html`. Wygląd: `style.css`.

## Grafika

`paper.webp`: autorska grafika wygenerowana narzędziem image_gen. Prompt: Handmade paper-cut Valentine stationery, pale blush paper, folded raspberry-red and coral hearts at outer edges, mint botanical sprig, clear central area, no text, no frame.
